# ExposureCamcorder 详细游玩指南

## 1. 模组定位

`ExposureCamcorder` 不是一套完全独立的相机模组，而是 `Exposure` 的动态照片扩展。

它做的事情很明确：

- 让 `Exposure` 的原版相机支持“录制模式”
- 让你把连续拍下来的多帧画面封装成一张“动态照片”
- 让动态照片进入 `Exposure` 现有的查看、相册、相框与导出链路

这意味着你游玩时的核心入口不是新机器，而是 `Exposure` 里的相机、胶卷、相册和相框系统。

## 2. 适用环境

本指南基于当前仓库实现编写：

- Minecraft `1.21.1`
- Exposure `1.9.16`
- 支持平台：`Fabric`、`NeoForge`

前置要求：

- 必须安装 `Exposure`
- 建议先会使用 `Exposure` 的基础相机与装片流程

## 3. 这模组到底加了什么

这个模组当前的核心新增内容只有三类：

- 动态胶卷
- 已冲洗的动态胶卷
- 动态照片

它没有新增一台独立“摄像机”物品。实际录制仍然使用 `Exposure` 的相机，只是相机多了一个“录制模式”。

## 4. 动态胶卷体系

### 4.1 胶卷分类

模组一共提供 6 个系列：

| 系列 | 色彩 | 分辨率 | 基础容量 |
|---|---|---:|---:|
| 普通彩色动态胶卷 | 彩色 | 跟随 Exposure 默认照片分辨率 | 默认 40 帧 |
| 普通黑白动态胶卷 | 黑白 | 跟随 Exposure 默认照片分辨率 | 默认 40 帧 |
| 高分辨率彩色动态胶卷 | 彩色 | 640 px | 40 帧 |
| 高分辨率黑白动态胶卷 | 黑白 | 640 px | 40 帧 |
| 超高分辨率彩色动态胶卷 | 彩色 | 960 px | 40 帧 |
| 超高分辨率黑白动态胶卷 | 黑白 | 960 px | 40 帧 |

说明：

- 普通动态胶卷的基础容量默认是 `40` 帧，但服务端配置可以改
- 高分辨率和超高分辨率胶卷的基础容量在当前实现里固定为 `40` 帧
- 所有系列都提供 `80 / 160 / 320 / 600` 帧版本

### 4.2 容量与时长怎么理解

默认录制间隔是 `2 tick/帧`，也就是每秒 10 帧。

按照默认值估算：

- `40` 帧约等于 `4` 秒
- `80` 帧约等于 `8` 秒
- `160` 帧约等于 `16` 秒
- `320` 帧约等于 `32` 秒
- `600` 帧约等于 `60` 秒

物品 tooltip 也会直接显示：

- 分辨率
- 总容量
- 剩余帧数
- 预计剩余时长

## 5. 合成路线

### 5.1 普通彩色动态胶卷

配方材料：

- 铁粒 `1`
- 青金石 `2`
- 铁锭 `2`
- 红石 `2`
- 干海带 `2`

### 5.2 普通黑白动态胶卷

配方和普通彩色版基本一致，只是把青金石换成骨粉：

- 铁粒 `1`
- 骨粉 `2`
- 铁锭 `2`
- 红石 `2`
- 干海带 `2`

### 5.3 高分辨率彩色动态胶卷

配方材料：

- 金粒 `1`
- 青金石 `2`
- 金锭 `2`
- 红石 `2`
- 干海带 `2`

### 5.4 高分辨率黑白动态胶卷

按当前仓库里的实际配方：

- 铁粒 `1`
- 骨粉 `2`
- 铁锭 `2`
- 红石 `2`
- 干海带 `2`

### 5.5 超高分辨率彩色动态胶卷

升级材料：

- 高分辨率彩色动态胶卷 `1`
- 钻石 `1`
- 紫水晶碎片 `1`
- 金块 `1`

### 5.6 超高分辨率黑白动态胶卷

升级材料：

- 高分辨率黑白动态胶卷 `1`
- 钻石 `1`
- 石英 `1`
- 铁块 `1`

### 5.7 容量升级链

所有系列都遵循同一套升级逻辑：

- `2` 个基础版合成 `80` 帧版
- `2` 个 `80` 帧版合成 `160` 帧版
- `2` 个 `160` 帧版合成 `320` 帧版
- `320` 帧版 `1` 个 + `160` 帧版 `1` 个 + `80` 帧版 `1` 个 + 钻石 `1` 个，合成 `600` 帧版

## 6. 正确的游玩流程

### 6.1 准备阶段

你需要先准备：

- `Exposure` 相机
- 任意一种动态胶卷

然后按 `Exposure` 原本的方式把动态胶卷装进相机。

### 6.2 切换到录制模式

拿着 `Exposure` 相机时，按默认热键 `R`。

相机会在两种状态之间切换：

- Photo mode：普通拍照模式
- Recording mode：录制模式

只有切到录制模式后，动态胶卷才会被当成可录制介质使用。

### 6.3 开始录制

切到录制模式后，执行 `Exposure` 相机原本的快门/拍摄操作，按右键开始录制，再次点击右键可以停止录制。

录制开始后会出现状态提示：

- `REC`
- 已记录帧数
- 剩余容量
- 剩余可录时长

### 6.4 录制什么时候结束

以下情况都会结束一次录制：

- 你再次点击右键
- 胶卷容量耗尽
- 达到服务端允许的录制时长上限
- 客户端帧上传超时或录制被中断
- 玩家离线


### 6.5 录制结束后你会得到什么

当前实现不是“松手直接出动态照片”，而是先把结果写回相机里的那卷动态胶卷。

录完以后，这卷胶卷会变成“已曝光但未冲洗”的状态，tooltip 会明确提示这卷胶卷需要先冲洗。

## 7. 冲洗与转片

### 7.1 彩色动态胶卷怎么冲洗

当前彩色动态胶卷的冲洗不再是“一套配方打天下”，而是分成 3 层：

- 基础显影药水
- 容量附加材料
- 分辨率附加材料

基础彩色显影药水如下：

- 粗制药水
- 浓稠药水
- 平凡药水

在这个基础上，不同容量还要额外补料：

| 容量 | 额外要求 |
|---|---|
| 40 帧 | 无 |
| 80 帧 | 萤石粉 `1` |
| 160 帧 | 额外浓稠药水 `1` + 萤石粉 `1` |
| 320 帧 | 额外粗制药水 `1` + 额外浓稠药水 `1` + 萤石粉 `1` |
| 600 帧 | 额外粗制药水 `1` + 额外浓稠药水 `1` + 额外平凡药水 `1` + 萤石粉 `1` |

不同分辨率还要再追加：

| 系列 | 额外要求 |
|---|---|
| 普通彩色动态胶卷 | 无 |
| 高分辨率彩色动态胶卷 | 紫水晶碎片 `1` |
| 超高分辨率彩色动态胶卷 | 钻石 `1` |

也就是说：

- `dynamic_hires_film_80` = 基础三药水 + 萤石粉 + 紫水晶碎片
- `dynamic_ultra_hires_film_600` = 2 份粗制药水 + 2 份浓稠药水 + 2 份平凡药水 + 萤石粉 + 钻石

冲洗结果统一是：

- `Developed Dynamic Color Film`

### 7.2 黑白动态胶卷怎么冲洗

黑白动态胶卷也改成了分层显影，但基础仍然比彩色简单。

基础黑白显影药水：

- 水药水

不同容量的附加要求：

| 容量 | 额外要求 |
|---|---|
| 40 帧 | 无 |
| 80 帧 | 石英 `1` |
| 160 帧 | 额外水药水 `1` + 石英 `1` |
| 320 帧 | 额外水药水 `1` + 石英 `2` |
| 600 帧 | 额外水药水 `2` + 石英 `2` + 萤石粉 `1` |

不同分辨率的附加要求：

| 系列 | 额外要求 |
|---|---|
| 普通黑白动态胶卷 | 无 |
| 高分辨率黑白动态胶卷 | 方解石 `1` |
| 超高分辨率黑白动态胶卷 | 方解石 `1` + 紫水晶碎片 `1` |

例如：

- `dynamic_hires_bw_film` = 水药水 + 方解石
- `dynamic_ultra_hires_bw_film_80` = 水药水 + 石英 + 方解石 + 紫水晶碎片
- `dynamic_ultra_hires_bw_film_600` = 3 份水药水 + 2 个石英 + 萤石粉 + 方解石 + 紫水晶碎片

冲洗结果统一是：

- `Developed Dynamic Black-and-White Film`

### 7.3 已冲洗胶卷怎么变成动态照片

拿着“已冲洗的动态胶卷”直接右键，就会把它转换成 `Dynamic Photograph`。

这一步不会把内容丢掉，录制得到的：

- 帧列表
- 录制间隔
- 预计时长
- 会话 ID

都会保留在动态照片里。

## 8. 动态照片怎么查看

### 8.1 基础查看

拿着 `Dynamic Photograph` 右键，就会打开查看界面。

打开后会：

- 自动开始播放，可调整播放倍速
- 显示封面帧作为静态预览后备

### 8.2 查看界面里的控制方式

界面底部有按钮，也支持快捷键。

默认快捷键如下：

- `Space`：播放 / 暂停
- `[`：减速
- `]`：加速
- `\`：恢复 1x 速度
- `Ctrl+E`：导出 GIF

当前实现的速度档位覆盖 `0.10x` 到 `2.00x`。

### 8.3 Tooltip 能看到什么

动态照片的 tooltip 会显示：

- 总帧数
- 录制间隔
- 预计时长

开启高级 tooltip 时，还能看到内部会话 ID。

## 9. 相册、相框与展示播放

这个模组最实用的一点，是它没有把动态照片做成孤岛物品，而是直接接进了 `Exposure` 的展示系统。

### 9.1 相册里的表现

动态照片放进相册后：

- 默认显示封面帧
- 可以像普通照片一样被点开查看
- 在相册界面中支持切换展示播放

### 9.2 相框里的表现

动态照片放进 `Exposure` 的相片展示实体后：

- 静止状态下只显示封面帧
- 开启播放后会在相框中播放整段动态照片

### 9.3 展示播放热键

默认热键是 `P`。

它的使用方式分成两种：

- 在相册界面里，把鼠标移到动态照片槽位上，再按 `P`
- 在世界里把准星对准正在展示动态照片的相框，再按 `P`

再次按 `P` 会停止播放。

这套逻辑是“按需播放”，不是默认所有相框永久动起来，所以更适合做展厅、相册墙和剧情回放。

## 10. GIF 导出

在动态照片查看界面里按 `Ctrl+E`，可以把当前动态照片导出为 GIF。

导出特点：

- 异步执行，不会立刻卡死界面
- 会提示导出开始、完成或失败
- 成功后聊天栏会给出可点击打开的文件
- 导出速度会参考你当前查看界面的播放速度

导出内容来自动态照片内部引用的曝光帧，所以如果某些帧资源没拿到，导出数量可能少于总帧数。

## 11. NeoForge + Create 兼容

在 `NeoForge` 侧，仓库里还额外提供了 `Create` 的序列装配配方。

它不是旧版那种“只灌药水”了，而是严格对应新显影规则：

- 彩色动态胶卷通过 `filling` 依次灌入粗制药水、浓稠药水、平凡药水
- 黑白动态胶卷通过 `filling` 灌入 `Water`
- 容量附加材料和分辨率附加材料通过 `deploying` 追加

对应关系可以这样理解：

| 系列 | Create 工序追加物 |
|---|---|
| 彩色 80+ 帧 | 萤石粉 |
| 黑白 80+ 帧 | 石英 |
| 高分彩色 | 紫水晶碎片 |
| 高分黑白 | 方解石 |
| 超高分彩色 | 钻石 |
| 超高分黑白 | 方解石 + 紫水晶碎片 |

如果你做整合包，这意味着动态照片可以自然接进 `Create` 的自动化生产线。

## 12. 实战建议

### 12.1 先选容量，再选分辨率

通常可以这么选：

- 想拍短循环表情、动作、招手：`40` 或 `80` 帧
- 想拍战斗片段、风景摇镜：`160` 或 `320` 帧
- 想做长剧情回放：`600` 帧

### 12.2 分辨率越高，越适合近距离展示

推荐场景：

- 普通分辨率：日常记录、量大管饱
- 640 px：相册展示、室内相框墙
- 960 px：重点纪念照、展馆核心作品、GIF 导出素材

### 12.3 黑白片更适合低成本叙事

黑白动态胶卷的基础显影仍然只围绕水药水展开，附加材料也比彩色线便宜，特别适合：

- 生存前期
- 剧情纪录片风格
- 大批量拍摄和归档

## 13. 常见问题

### 13.1 按 `R` 没反应

先检查：

- 你手上拿的是 `Exposure` 相机，不是别的物品
- 当前没有打开任何 GUI
- 客户端热键没有被别的模组占用

### 13.2 相机提示需要动态胶卷

这说明相机里没有装动态胶卷，或者装进去的不是这个模组新增的动态胶卷。

### 13.3 录完后为什么没直接变成动态照片

这是当前设计使然。

正确流程是：

1. 录制
2. 得到已曝光胶卷
3. 先冲洗
4. 再右键把已冲洗胶卷转成动态照片

### 13.4 相框里为什么只显示一张静态图

这是默认行为。动态照片在非查看状态下默认只显示封面帧。

要让它动起来：

- 鼠标或准星对准对应展示对象
- 按 `P` 开启展示播放

### 13.5 为什么导出 GIF 失败

常见原因有：

- 这张动态照片没有可用帧
- 曝光资源还没加载完成
- 已经有一个 GIF 导出任务在运行

## 14. 给整合包作者的可调项

服务端当前有 3 个最重要的动态照片配置：

- `default_capture_interval_ticks`
- `max_recording_duration_ticks`
- `default_dynamic_film_max_frames`

默认值分别是：

- `2`
- `80`
- `40`

如果你想把这个模组调成“Live Photo 风格”，可以降低容量和时长。
如果你想把它调成“长镜头剧情记录器”，可以提高默认容量并配合更高阶胶卷。

## 15. 一句话总结玩法闭环

最标准的游玩闭环就是：

1. 合成动态胶卷
2. 装进 `Exposure` 相机
3. 按 `R` 切到录制模式
4. 按住快门录一段
5. 拿出已曝光胶卷去冲洗
6. 右键已冲洗胶卷转成动态照片
7. 在查看器、相册、相框里播放，或者导出成 GIF

如果你是第一次玩，最推荐的入门路线是：

- 先做一卷普通黑白动态胶卷
- 录一个 `40` 帧的小动作
- 用基础黑白片先做一张，按当前容量配方补上水药水和附加材料洗出来
- 再把成片挂进相框里按 `P` 播放

这是最便宜、也最容易马上看到成就感的一条线。
