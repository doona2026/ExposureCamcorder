# `version/1.20.1` 独立双线实施计划

## 目标

- 保留根目录 1.21.1 主线不变。
- 新增 `version/1.20.1` 独立工程根。
- 在 `version/1.20.1` 中同时提供 Fabric 与 Forge 两个平台。
- 让后续维护可以同步两条线，但每条线各自编译、各自打包。

## 固定决策

- 根目录继续代表 1.21.1。
- `version/1.20.1` 单独承担 1.20.1 兼容。
- 1.20.1 线使用旧版 API 和旧版数据持久化方式。
- 共享图片、语言和说明文案可以同步，编译源码不强制共用。

## 执行任务

1. 搭建 `version/1.20.1` 工程骨架。
   - 新增：`version/1.20.1/settings.gradle`、`version/1.20.1/build.gradle`、`version/1.20.1/gradle.properties`。
   - 新增：`version/1.20.1/gradlew`、`version/1.20.1/gradlew.bat`、`version/1.20.1/gradle/wrapper/*`。
   - 新增：`version/1.20.1/common/build.gradle`、`version/1.20.1/fabric/build.gradle`、`version/1.20.1/forge/build.gradle`。
   - 目标：`version/1.20.1` 能作为独立 Gradle 根打开并识别 `common`、`fabric`、`forge` 三个模块。
   - 验证：`./gradlew.bat -p version/1.20.1 projects`

2. 固定 1.20.1 版本矩阵并接入依赖。
   - 在 `version/1.20.1/gradle.properties` 写入 1.20.1 专用版本号。
   - 配置 Minecraft、Java、Fabric Loader、Fabric API、Forge、Parchment 和 Exposure 的 1.20.1 兼容版本。
   - 目标：1.20.1 工程能解析所有依赖，不污染根目录 1.21.1。
   - 验证：`./gradlew.bat -p version/1.20.1 dependencies`

3. 迁移 common 代码与资源基线。
   - 新增：`version/1.20.1/common/src/main/java/io/github/exposure_camcorder/**`。
   - 新增：`version/1.20.1/common/src/test/java/io/github/exposure_camcorder/**`。
   - 新增：`version/1.20.1/common/src/main/resources/**`。
   - 复制当前稳定业务逻辑、测试、语言、模型、配方和基础纹理作为起点。
   - 将 1.20.1 不支持的资源格式改写为旧版格式。
   - 验证：`./gradlew.bat -p version/1.20.1 :common:processResources`

4. 改造 1.20.1 common 的物品状态存储。
   - 新增：`version/1.20.1/common/src/main/java/io/github/exposure_camcorder/world/data/DynamicItemStackData.java`。
   - 调整：`world/component/**`、`world/item/**`、`world/item/camera/**`、`util/DynamicPhotographFactory.java`。
   - 目标：用 1.20.1 兼容的数据存储替代 1.21.1 数据组件实现。
   - 验证：`./gradlew.bat -p version/1.20.1 :common:test`

5. 回填 1.20.1 common 的网络、录制与播放逻辑。
   - 调整：`network/packet/**`、`client/capture/**`、`client/playback/**`、`client/render/**`、`client/gui/screen/**`。
   - 目标：1.20.1 线的录制、预览、导出与动态照片展示在 common 层可编译可测试。
   - 验证：`./gradlew.bat -p version/1.20.1 :common:compileJava :common:test`

6. 实现 Fabric 1.20.1 平台入口。
   - 新增：`version/1.20.1/fabric/src/main/java/io/github/exposure_camcorder/fabric/**`。
   - 新增：`version/1.20.1/fabric/src/main/resources/fabric.mod.json`、`exposure_camcorder-fabric.mixins.json`。
   - 目标：Fabric 1.20.1 能启动、注册、收包、绑定按键。
   - 验证：`./gradlew.bat -p version/1.20.1 :fabric:compileJava :fabric:processResources`

7. 实现 Forge 1.20.1 平台入口。
   - 新增：`version/1.20.1/forge/src/main/java/io/github/exposure_camcorder/forge/**`。
   - 新增：`version/1.20.1/forge/src/main/resources/META-INF/mods.toml`、`exposure_camcorder-forge.mixins.json`。
   - 目标：Forge 1.20.1 能启动、注册、收包、绑定按键。
   - 验证：`./gradlew.bat -p version/1.20.1 :forge:compileJava :forge:processResources`

8. 完成 1.20.1 工程的最终构建验证。
   - 运行：`./gradlew.bat -p version/1.20.1 clean build`
   - 目标：Fabric 与 Forge 两个平台都能产出可发布 jar。
   - 额外检查：确认 `version/1.20.1` 的资源、图标、语言、模型和元数据都落在正确路径。

## 成功标准

- `version/1.20.1` 可独立构建。
- Fabric 和 Forge 1.20.1 jar 都能生成。
- 根目录 1.21.1 不被回归破坏。
- 后续修改能按版本分别同步，而不是靠单工程条件分支硬撑。
